## REMOVED Requirements

### Requirement: Public showcase represents the local product accurately

**Reason**: The public root is now the functional browser application.

**Migration**: Use the `browser-pages-workspace` capability.

### Requirement: Public artifact is deterministic and data-free

**Reason**: The artifact now contains deterministic application JavaScript and can process explicit local files in memory.

**Migration**: Use browser application artifact and privacy requirements.

### Requirement: Pages publication is explicit and reproducible

**Reason**: Publication belongs to project tooling after the showcase capability is removed.

**Migration**: Preserve guarded manual publication under project tooling.
